This repo hosts the LLM pipeline designed for the project ["Tap & Say"](https://dl.acm.org/doi/full/10.1145/3706598.3713376), a novel multimodal system that combines touch interactions with Large Language Models (LLMs) for accurate text correction.

The pipeline generates synthetic test data and fine-tunes a modified FLAN-T5 with a touch-location-informed attention layer. For details, please refer to this publication: https://dl.acm.org/doi/full/10.1145/3706598.3713376
